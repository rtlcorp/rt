# RT Passbook

Passbook ng mga borrower, investor at taga-withdraw ng RT LENDING CORP.

- May sariling link ang bawat isa. Walang account na kailangan.
- Naka-lock ang datos ng bawat isa. Sariling link lang ang nakakabukas nito.
- `admin.html` — para lang sa may-ari (may lihim na password).
- `data.json` — ina-upload pagkatapos ng bawat sweldo.
